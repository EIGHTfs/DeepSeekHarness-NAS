## 一·结论（10111 两个根因，均已实测定位）

1. **manifest 含未知字段 changelog** → GetCloudDetail 解析 nil panic → 10111（已修，mod8 铁证）
2. **wizard/uninstall 为 `[]` 空数组** → GetCloudDetail 解析 WizardData nil → 10111（本轮新锁定，待修 build-fpk.sh）

> 对照证据：exp-i(仅换 uninstall 为对方版)✅ 成功 / exp-j(uninstall 仍 `[]`)❌ 10111 —— 其余 4 组文件(privilege/ui-config/manifest/resource)单独还原均 ✅ 成功，全部排除。

## 二、当前结论（每轮实验后更新）

1. **changelog 是 10111 的直接触发器**（实验 3 铁证：对方成功包仅加 changelog 一行 → 10111），已从 build-fpk.sh 删除。
2. **但全新态下，删了 changelog 我们外层仍 10111**（实验 7/8）；对方外层 + 我们 app.tgz + 同 appname → 全新可装（实验 11）。
3. **云端不是根本原因**：mod7 与我们的包同为全新态、同 appname、checksum 也都 ≠ 云端记录值 22fa1bd0，mod7 却成功——差异在**外层文件内容**，不在云端记录。
4. GetCloudDetail 会解析外层 wizard 等文件：换上对方 wizard 后错误码从 10111（WizardData nil）→ 10500（InstallTask nil），说明外层文件被参与校验。
5. **下一步二分**：privilege 已排除。剩余 4 组（wizard / manifest / ui/config / config/resource）逐个还原定位最小差异集。

## 四、复现步骤（装前必做）

```bash
# 停 + 清记录 + 清目录（回全新态）
appcenter-cli stop DeepSeekHarness-NAS 2>&1 | grep -a "stop success"
psql -U postgres -d appcenter -c "DELETE FROM app WHERE app_name='DeepSeekHarness-NAS';"
psql -U postgres -d appcenter -c "DELETE FROM app_package WHERE app_name='DeepSeekHarness-NAS';"
for p in /var/apps/DeepSeekHarness-NAS /vol2/@appcenter/DeepSeekHarness-NAS /vol2/@appdata/DeepSeekHarness-NAS /vol2/@appmeta/DeepSeekHarness-NAS /vol2/@appshare/DeepSeekHarness-NAS; do
  [ -e "$p" ] && mv "$p" "${p}-exp$(date +%H%M%S)"
done

# 安装
appcenter-cli install-fpk <包路径> 2>&1 | grep -aE "Error|10111|10234|10500|installed|Installation"
```
